## 罠と注意点

- **`gh pr edit`はprojectCards GraphQL deprecationエラーで失敗する**．PR本文更新は `gh api repos/<owner>/<repo>/pulls/<N> -X PATCH -F body=@<file>` を使う
- **日本語ファイル名はgitがquoteして出力する**（`"contexts/\343..."`）ため，`git diff --name-only | grep -vE '^contexts/'` がすり抜ける．`git -c core.quotepath=false` を付けて確認する
- **ローカルrebase後のgit push --force-with-leaseは，直前にgit fetchしていないと失敗する**（リモート追跡refが古いため）．fetch fork main→push の順で行う
- **複数セッションが同一作業ツリーを共有すると変更が混在する**．本セッションでは別セッションのadjust実装と自エージェントのthreads変更が混在した．対処：稼働中エージェントに即座にコミット禁止をSendMessageし，コーディネータがhunk単位（キーワード判別＋git apply --cached）で分離コミットした
- **別セッションのdevlogは結果欄が未記入（「結果は下記」のまま）の場合がある**．コミット前に現物を検証・補完する
- **editable install（pip install -e .）は単一Python環境を占有する**ため，git worktreeでエージェントを並行させてもビルド・テストは衝突する．C++ビルドを伴う並行作業には別venvが必要（本プロジェクトでは逐次実行で回避）
- devlogにコミットハッシュを書く際，コミット作成前に書くと捏造になる（本セッションで一度誤記し，実ハッシュ確認後に修正した）．ハッシュはrebase後に確定してから記入する
- サブエージェントの待機宣言ターン終了は指示に明記しても起こる（threadsエージェントはSendMessageの追指示で復帰）
